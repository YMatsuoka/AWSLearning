# AWS Certified Cloud Practitioner (CLF-C02) 合格プラン 🚀

## 1. 目的
- 1ヶ月の短期集中で AWS Certified Cloud Practitioner (CLF-C02) に合格する。
- AWSの主要サービスとクラウドの概念を理解し、実務や上位資格への土台を作る。

## 2. 目標スケジュール
- **開始日**: 2026年6月9日
- **試験予定日**: 2026年7月上旬
- **合格ライン**: 1000点満点中 700点以上

## 3. フェーズ別アクションアイテム

### 第1週：全体像と基本の「キ」
- [ ] AWS Cloud Practitioner Essentials (Japanese) を完走する
- [ ] クラウドの定義（5つの特性、3つのデプロイモデル、3つのサービスモデル）を理解する
- [ ] グローバルインフラストラクチャ（リージョン、AZ、エッジロケーション）を把握する

### 第2週：主要サービスの深掘り
- [ ] コンピューティング: EC2, Lambda, ECS, Fargate
- [ ] ストレージ: S3, EBS, EFS
- [ ] データベース: RDS, DynamoDB, Aurora
- [ ] ネットワーク: VPC, Subnet, IGW, Security Group, ACL
- [ ] 管理・ガバナンス: CloudWatch, CloudTrail, AWS Config

### 第3週：セキュリティ・責任共有・コスト
- [ ] 責任共有モデルの徹底理解（AWSの責任 vs ユーザーの責任）
- [ ] IAM（ユーザー、グループ、ロール、ポリシー、MFA）の設定ルール
- [ ] 請求と料金: Savings Plans, Reserved Instances, Spot Instances
- [ ] サポートプラン（Basic, Developer, Business, Enterprise）の比較

### 第4週：総仕上げ・模擬試験
- [ ] AWS公式の無料模試を受ける
- [ ] 外部の模擬問題集（Udemy等）で 80% 以上の正答率を目指す
- [ ] 苦手分野を特定し、自分の言葉で「チートシート」を作成する

## 4. 実行環境のセットアップ
- [ ] Gitリポジトリの初期化
- [ ] GitHub Issues でタスク管理を開始する
- [ ] 学習ログを格納するディレクトリ（`notes/`）の作成

## 5. 検証・振り返り
- 各週の終わりに理解度を確認。
- 模試で間違えた問題は必ずドキュメントに立ち返って確認する。
