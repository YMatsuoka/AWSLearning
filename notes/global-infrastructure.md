# AWSグローバルインフラストラクチャ（Azure対比メモ） 🌍

AWSが世界中にどうやって基地（データセンター）を配置しているか、Azureの知識をベースに整理したよ！

## 1. リージョン (Region)
物理的に離れた、世界各地にある場所の塊。

- **AWS**: 全世界に30以上（今も増えてる）。
- **Azure**: 同じく「リージョン」と呼ぶ。
- **ポイント**: 
  - 基本的にデータはリージョンを跨いで勝手にコピーされない（データ主権）。
  - 各リージョンは独立してるから、1つが死んでも他には影響しない。

## 2. アベイラビリティーゾーン (AZ)
1つのリージョンの中にある、独立したデータセンター群。

- **AWS**: 1つのリージョンに最低 **3つ以上** あるのが基本。
- **Azure**: **可用性ゾーン (Availability Zones)** と同じ。
- **ポイント**: 
  - 各AZは物理的に離れた場所にあるけど、爆速な専用ネットワークで繋がってる。
  - **高可用性（Multi-AZ）**: 1つのAZが洪水とかで爆死しても、別のAZで動いていればシステムは止まらない！

## 3. エッジロケーション (Edge Location)
ユーザーの近くに配置された、配信専用の小さい基地。

- **AWS**: 全世界に450以上ある。
- **Azure**: **エッジサイト / CDNの拠点** に相当。
- **ポイント**: 
  - CloudFront（CDN）や Route 53（DNS）がここを使って爆速配信する。
  - リージョンやAZとは別物。データの「一時置き場（キャッシュ）」として使う。

## 4. 特殊なインフラ（試験に出ると「つよ」ってなるやつ）
- **Local Zones**: 
  - 大都市の近くにあるミニリージョン的なやつ。超低遅延が必要な時用。
  - Azure: **Azure Edge Zones** に近い。
- **AWS Wavelength**: 
  - 5Gネットワークの中にAWSの機材を置くやつ。モバイル向けの超爆速通信用。
  - Azure: **Azure for Operators** 的なノリ。
- **AWS Outposts**: 
  - 自分の会社のデータセンターに、AWSと同じ機材をドーンと置くやつ。
  - Azure: **Azure Stack** と同じ！

## 💡 試験に出る「インフラの力関係」まとめ
1. **リージョン**（一番でかい）
2. **アベイラビリティーゾーン (AZ)**（リージョンの中にある）
3. **データセンター**（AZの中にある。1つのAZに複数のDCがあることもある）

**「リージョン > AZ > データセンター」** この順番だけはマジで忘れないで！🔥
